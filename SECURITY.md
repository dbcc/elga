# Security policy

## Supported versions

Until tagged releases begin, only the latest revision of the default branch is
supported. After releases begin, security fixes will target the newest release.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting form in the repository's
**Security** tab when it is available. Do not disclose an unpatched
vulnerability in a public issue.

Include the affected revision, Windows version, reproduction steps, expected
impact, and any relevant crash information. Reports involving a malformed
Media Foundation sample should also identify the negotiated capture format and
mode. Please allow maintainers time to reproduce and prepare a fix before
public disclosure.

Ordinary crashes, device compatibility problems, and performance regressions
that do not expose a security boundary can use the public bug-report template.
